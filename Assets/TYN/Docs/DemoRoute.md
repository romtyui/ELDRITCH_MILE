## 為什麼需要這份設定

正常的地圖生成會產出：

| 節點類型 | 對應 Stage | 現況 |
|---|---|---|
| `Event` | `Explore` | ✅ **完整實作** |
| `Dialogue` | `Dialogue` | ✅ **完整實作**（三個選項＝判定目標，用機率卡打） |
| `Shop` | `Shop` | ✅ **完整實作**（八格貨架、金幣、依區域換貨、商人氣泡） |
| `SpecialEvent` | `SpecialEvent` | 🔶 挑一張牌可用，但**文案與玩法未定**，內容還是佔位 |
| `Combat` / `Boss` | `Battle` | ❌ **完全沒有**，戰鬥還沒接（跨隊需求 A） |

而預設的 `combatChance` 是 **0.55** —— 中間層有一半以上是戰鬥節點，最後一層固定是 Boss。

點到沒有 prefab 的節點不會當掉（`StageHost` 有 null 防護），但**畫面會停在一個空的 Stage 上走不下去**，
Console 只會有一行 `[StageHost] 找不到 Battle 的 prefab`。

所以 demo 路線避開戰鬥，把其餘四種都走一遍。

## 三個 Stage 現在都是真的了（2026-08-18）

| Stage | 現在會發生什麼 |
|---|---|
| `Dialogue` | 坎貝爾的開場白 → 三個選項攤開，**每個選項都是判定目標**。<br>hover 手牌看各選項的成功率、拖曳或點選出牌、成功的選項會結案 |
| `Shop` | 商人（冷原人）冒出招呼氣泡 → **八格貨架**，武器／食物／收藏品三類<br>→ 點商品扣金幣 → 點 EXIT 標籤 → 「確定要離開嗎？」→ 回地圖 |
| `SpecialEvent` | 攤幾張牌、挑一張帶走。機制可用，**但文案與玩法還沒設定**，內容是佔位 |

> 文件：[Phase6_Dialogue.md](Phase6_Dialogue.md)（對話）、[Phase7_ShopAndData.md](Phase7_ShopAndData.md)（商店與資料層）

### 對話節點的幾個看點

- **關鍵字會依屬性上色** —— 「你到底是<u>什麼</u>東西？」的「什麼」是藍的（邏輯）
- **判定當下選項會演一次「霧凝聚又散去」**，中間換成屬性色的「成功／失敗」
- **成功的選項就結案**（變暗、不再接受出牌）；失敗可以再試，但機率會衰減
- 三個選項都成功 → 自動收尾

### 商店的幾個看點

- 商人會**隨機挑一句招呼**，點他會依序講閒聊（**待機自言自語目前關閉**）
- 買不起的商品變暗但**還是點得動** —— 點下去會聽到「錢不夠」，比按不動好懂
- **同一個節點重進，商品一模一樣**（亂數綁節點，不然離開再進來就能重骰）

## 這條路線會經過什麼

```
主選單
  └─▶ 地圖下拉（5 個節點的直線）

  ① 探索 ─ 進房間
      ├─ 點普通木箱      → 直接開，拿到道具（撬棍／倉庫鑰匙）
      ├─ 點上鎖的箱子    → 打牌環節
      │     ├─ 拖曳或點兩下出牌
      │     ├─ hover 看各張牌的成功率（直覺牌對它是 ✕，會變暗）
      │     ├─ 判定結果即時顯示，第二次起附「這是你嘗試的第 N 次」
      │     ├─ 失敗五次 → 問要不要用撬棍再來一輪（衰減重置、重抽手牌）
      │     └─ 不重試 → 箱子結案（換圖、不再可點）
      └─ 點 ExitTag → 「確定要離開嗎？」→ 是 → 回地圖

  ② 對話 ─ 開場白 → 三個選項
      ├─ hover 手牌 → 三個選項各自顯示成功率
      ├─ 拖曳或點兩下出牌
      ├─ 成功 → 選項演一次動效後結案（變暗）
      ├─ 失敗 → 留著可以再試，但機率衰減
      └─ 三個都成功、或手牌用盡 → 收尾 → 回地圖

  ③ 商店 ─ 商人的招呼氣泡 → 八格貨架
      ├─ 點商品 → 扣金幣 → 該格標「已售出」
      ├─ 點商人 → 依序講閒聊
      └─ hover 右下角 EXIT → 標籤滑出來 → 點 → 「確定要離開嗎？」

  ④ 特殊事件 ─ 挑一張牌（機制可用，文案未定）

  ⑤ 探索 ─ 再走一次房間。**這次手牌裡會多出 ④ 給的那張牌**
```

第 ⑤ 站是刻意安排的 —— 它證明 ④ 給的牌真的進了牌組，流程是**通的**而不是各自獨立的畫面。

**沒有涵蓋的**：戰鬥。下週三／四與戰鬥組對接，見 [SystemsStatus.md](SystemsStatus.md) §2.1。

## 跑之前建議確認的三件事

1. **Play 之前存過場景**（Ctrl+S）—— 今天有幾項設定是透過工具改的
2. **Console 清空** —— 方便看 `[判定]` `[打牌]` `[探索]` 這些流程 log
3. **地圖 hover 目前沒有視覺回饋** —— 見下

### 地圖節點 hover 現在沒反應（今天的變更）

原本 hover 會放大，2026-08-16 改成顯示 tooltip，但**tooltip 面板還沒在編輯器裡建**。
所以現在滑過節點沒有任何回饋。兩個選擇：

| 選項 | 做法 | 花費 |
|---|---|---|
| **A. 暫時把縮放開回來**（demo 前建議） | `MapNodeUI`（三個 NodeUI prefab）的 `Scale Hover` 設 **`1.1`** | 1 分鐘 |
| **B. 把 tooltip 面板建起來** | 見 [MapPolish.md](MapPolish.md) | 10 分鐘 |

A 和 B 不衝突，之後 tooltip 上線再把 `Scale Hover` 調回 `1` 即可。
