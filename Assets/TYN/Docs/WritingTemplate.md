# 文案填寫表

> **你只要填這幾張表，剩下的我們搬進遊戲。** 不用開 Unity，不用管檔名、編號、標籤。
> 更新：2026-08-18

---

## 這份怎麼用

每一節都是「**一段說明 → 空白表 → 每一欄要填什麼 → 一個填好的範例**」。
直接複製表格到文件或試算表裡填就好。

**填不完整完全沒關係。** 想不到的欄位留白，我們會用預設值或回頭問你。
唯一希望你盡量填滿的是**名字**與**台詞／內文** —— 那些只有你想得出來。

先看最後兩個附錄（[獎懲能寫什麼](#附錄-a獎懲能寫什麼)、[觸發條件能寫什麼](#附錄-b觸發條件能寫什麼)），
那是目前遊戲**實際做得到的事**。寫在清單外的東西不是不能寫，但要先問一下做不做得出來。

## 一、糧食

漁村撿得到、商店買得到的吃的。玩家在戰鬥外使用，大方向是「**回 HP、掉 SAN**」。

| 名字 | 說明（一兩句） | 是不是漁獲 | 看了舒不舒服 | 想要的效果 |
|---|---|---|---|---|
|  |  |  |  |  |
|  |  |  |  |  |

**逐欄說明**

- **名字** —— 玩家看到的。現有的走「日常物件被輕輕扭曲」的調性，可以參考。
- **說明** —— 背包裡點開會看到的描述。一兩句就好，不用寫成小說。
- **是不是漁獲** —— 是／否。漁村的箱子與商店會**特別容易**出漁獲，其他地方比較少。
- **看了舒不舒服** —— 正常／有點不對勁。「不對勁」的東西會出現在比較深的寶箱裡。
- **想要的效果** —— 用白話寫，例如「回一點血，但看了會反胃」。
  ⚠️ **糧食的數值目前還沒有地方填**（「使用道具」的介面還沒做），
  所以這一欄現在是**願望清單**，先寫著，之後一起定。

## 二、收藏品（遺物）

撿到就一直帶在身上的東西。**大多數的效果是在戰鬥中生效**，所以效果那一欄
最後會交給戰鬥組實作 —— 但「想要什麼感覺」由你決定。

| 名字 | 說明（一兩句） | 稀有度 | 祝福／詛咒 | 想要的效果 | 從哪拿到 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |

**逐欄說明**

- **稀有度** —— 普通／罕見／稀有。**這是它的本質**，不是掉落率。
  （「哪個箱子多少機率開出它」是我們調的，你不用管。）
- **祝福／詛咒** —— 祝福／詛咒／都不是。大綱有這個分類，先留著。
- **想要的效果** —— 白話。例如「戰鬥開始時多抽一張牌」「受傷時有機會反擊」。
- **從哪拿到** —— 商店買／某個事件給／寶箱開出來。不確定就留白。

**已經有的**

| 名字 | 稀有度 | 來源 |
|---|---|---|
| 老舊釣竿 | 普通 | 事件《無人的小船》 |
| 燒毀的樂譜 | 普通 | 商店 |
| 染血釣竿 | 罕見 | 商店 |
| 混沌撲克 | 罕見 | 商店 |
| 貪婪的大口 | 罕見 | 事件《好餓好餓的貪吃鬼》 |
| 嶄新釣竿 | 稀有 | 商店 |
| 人魚肉 | 稀有 | 事件《海市蜃樓》 |
| 螺湮御守 | 稀有 | 事件《螺湮的祝福》 |

> ⚠️ 另外有 10 件寫好但**還沒進遊戲**的：無聲的小鈴、指不到北的羅盤、縫錯位置的布偶、
> 不屬於任何門的鑰匙、起霧的單片鏡、褪色的面具、走音的音樂盒、暗紅的寶石、
> 星塵般的顏料、不是人的牙。
> **這些還要不要用？** 要的話請幫它們各定一個稀有度，我們就接進去。

## 三、角色台詞

這裡寫的**全部是氣泡台詞** —— 手遊裡點一下角色，他頭上冒出一句話那種。

**它跟劇情對話是兩件事：**

| | 氣泡台詞（這一張表） | 劇情對話（下一節） |
|---|---|---|
| 長什麼樣 | 頭上一個小氣泡，幾秒後自己消失 | 下方對話框，要點才推進 |
| 有沒有分支 | 沒有 | 有 |
| 漏看了 | 沒差 | 有差 |
| 用途 | **氣氛**、性格 | **內容**、劇情 |

一個角色一張單：

```
角色名字：
一句話說他是誰：
會出現在哪（漁村／商店／到處都是）：
```

| 什麼時候說 | 台詞（每組至少 3 句） |
|---|---|
| **見面第一句**<br>進商店、開始對話的那一刻 | 1.<br>2.<br>3. |
| **閒聊**<br>玩家點他、或發呆一陣子 | 1.<br>2.<br>3.<br>4. |
| **成交**<br>在商店買下東西時 | 1.<br>2.<br>3. |
| **玩家過關**<br>對話裡判定成功時 | 1.<br>2.<br>3. |
| **玩家失手**<br>對話裡判定失敗時 | 1.<br>2.<br>3. |
| **道別**<br>這段對話結束時 | 1.<br>2.<br>3. |
| **彩蛋**（可留白）<br>特定條件成立才會講 | 條件：<br>1.<br>2. |

**幾件要知道的事**

- **每組至少 3 句。** 只有 1 句的話，玩家連點三下會聽到三次一樣的。
- **見面／成交／成敗／道別是隨機挑一句**；**閒聊是照順序輪**（連點才不會撞句）。
- **每一句都要是完整的句子**，不要留空格給程式填東西 ——
  成交台詞就寫「謝謝惠顧～下次也請務必光臨本店哦？」，
  不要寫「買了○○啊，好眼光」那種要塞商品名進去的形式。
- **某一組不寫也合法** —— 代表這個角色不講那種話。
  例如純劇情角色可以完全沒有「成交」。
- **表情差分**：如果某一句你希望是特定表情（得意／冷淡／驚訝／苦笑），
  在句子後面註明就好，例如「……你比上一次更難應付了。（得意）」。
  現在沒有表情的圖，我們會先用預設立繪，之後圖進來自動換。

**已經有的角色**

| 名字 | 出現在 | 台詞完整度 |
|---|---|---|
| 坎貝爾 | 到處都是 | ✅ 齊全 |
| 商人 | 商店 | 缺成敗／道別（他不進對話節點，暫時不缺） |
| 時藏 | 漁村 | ⚠️ **只有見面與閒聊**，缺成功／失敗／道別 |

> ⚠️ **時藏現在還不能在對話節點上場**，缺的就是上面那三組（還缺一張立繪）。
> 如果你想讓他當漁村的對話角色，這三組是必須的。

## 四、事件

「探索途中，每前進到下一張地圖，滿足條件就有機會遇到」的那些。
大綱〈事件〉那一章已經寫好八個 —— 這張表是給**新事件**用的。

```
標題：
什麼時候會遇到（白話）：
一場遊戲只會遇到一次嗎：是／否
遇到了一定發生嗎，還是還要再抽一次機率：
```

**事件內文**（一行 = 玩家看到的一則訊息，點一下看下一則）

```

```

**選項**（最多 3 個，也可以 0 個）

| | 選項名字 | 選了之後的內文 | 獎懲 |
|---|---|---|---|
| A |  |  |  |
| B |  |  |  |
| C |  |  |  |

**逐欄說明**

- **標題** —— 遊戲裡會顯示成《標題》。
- **什麼時候會遇到** —— 白話寫就好，例如「身上有糧食的時候」「玩久一點之後」。
  能不能做得到請對一下 [附錄 B](#附錄-b觸發條件能寫什麼)。
- **只會遇到一次嗎** —— 大綱寫「從**未觸發過**的事件中隨機」，所以預設是「是」。
- **還要再抽一次機率嗎** —— 大部分不用。《螺湮的祝福》是「打倒祭司後 **30%** 機率」，
  那個 30% 就填在這裡。**跟條件不一樣**：條件不成立是永遠不能發生，
  機率沒中只是這次沒中，下次還有機會。
- **事件內文** —— ⚠️ **你的分行就是玩家看到的斷句**，見下。
- **選項名字** —— 玩家點的那一行，大綱裡的粗體字（「往上看」「開門」）。
- **獎懲** —— 白話寫，我們對照 [附錄 A](#附錄-a獎懲能寫什麼) 實作。
  ⚠️ **不要在內文裡手寫「（【深淵】的侵蝕度+5%）」** —— 遊戲會自動加上那一行，
  手寫的話之後數字調整兩邊會不同步。

### 分行 = 斷句，這是這張表最重要的一欄

事件內文**不是一次全部倒出來**，而是一句一句播，玩家點一下看下一段。

大綱裡的內文常常是一大段沒斷句的文字，例如：

> 沙沙沙........耳邊響起海浪的聲音。一陣腥粘的海風帶著腐爛的氣味朝你吹來。對於眼前的場景，你感到難以置信。那是一座被迷霧圍繞的，漁村。你觀望四周……

我們把它斷成這樣：

```
沙沙沙........耳邊響起海浪的聲音。一陣腥粘的海風帶著腐爛的氣味朝你吹來。
對於眼前的場景，你感到難以置信。那是一座被迷霧圍繞的，漁村。
你觀望四周，發現此處貌似被大海所圍繞。海的另一端是更加厚重的白霧，幾乎看不見遠方的景色。
爲何你會突然出現在這裏？剛才的道路是怎麽通到這座小島上的？
很快的，你放棄了思考。因爲，你的腦袋被另一種聲音所覆蓋。
……好餓。
```

玩家會看到 6 則訊息，最後單獨的「……好餓。」會自己佔一則 —— **那一下的效果是斷句給的**。

**斷句是你的工作，不是我們的。** 分得好不好直接決定這個事件讀起來的節奏，
而那是文案的專業，我們替你分只會分壞。

### 已經有的八個事件

| 標題 | 什麼時候遇到 | 狀態 |
|---|---|---|
| 暴食之深淵 | 第一次進漁村 | ✅ |
| 無人的小船 | 隨時 | ✅ |
| 海市蜃樓 | 【深淵】侵蝕度 50% 以上 | ✅ |
| 損壞的祭壇 | 身上神牌少於 3 張 | 🔶 給神牌那一段還不會生效 |
| 喂米可吃飯 | 身上武器牌 20 張以上 | 🔶 銷毀武器牌還不會生效 |

| 好餓好餓的貪吃鬼 | 身上有糧食 | 🔶 選項 B 的戰鬥還不會發生 |

> ⚠️ **《螺湮的祝福》的選項 B 在大綱裡是空的** —— 需要你補一個「不撿」的選項名字與內文。

> 我們缺一種「隨機給一點東西」的做法，那是我們要補的，不是你。

## 附錄 A：獎懲能寫什麼

事件的選項、對話的成功獎勵，**目前能做到的就是這些**。
你用白話寫，我們對照著實作。

### 現在寫了就會生效

| 你可以寫 | 例子 |
|---|---|
| 給某件道具 | 獲得收藏品：老舊釣竿 |
| 扣掉某件指定的道具 | 失去「倉庫鑰匙」 |
| **扣掉某一類東西**（不指定哪一件） | 消耗 1 份糧食 |
| 某位神的侵蝕度增減 | 【深淵】的侵蝕度 +5% |
| SAN 增減（**用百分比**） | SAN −20% ／ 恢復 20% SAN |
| HP 增減（用百分比） | 回復 10% HP |
| 給錢 | 獲得 30 金幣 |
| 記下「這件事發生過」 | （之後別的事件可以用它當條件） |

> 「消耗糧食」請寫成「**消耗 N 份糧食**」而不是「消耗 1 條奇形怪狀的魚」——
> 玩家背包裡當下有哪一種魚，你不會知道，我們也不該替他決定。

### 現在可以寫，但要等系統做好才會動

**這四個照寫沒關係**，遊戲跑到那裡會安靜跳過，不會壞。

| 你可以寫 | 卡在哪 |
|---|---|
| 獲得 1 張神牌 | 神牌系統還不存在 |
| 永久銷毀 1 張武器牌 | 需要能編輯戰鬥牌組 |
| 隨機傳送到地圖上的其他地方 | 需要地圖跳轉 |
| 進入戰鬥（指定敵人） | 戰鬥還沒對接 |

### 現在還寫不了的

| 想寫的 | 為什麼 |
|---|---|
| 「隨機獲得一些資源」 | 我們缺一種「抽一張獎品表」的做法（**這是我們要補的**） |
| 糧食吃下去的具體數值 | 「使用道具」的介面還沒做 |
| 「坎貝爾在隊伍裡才會…」 | 隊伍（協助者）系統還不存在 |
| 「只有在漁村才會遇到」 | 「區域」這個概念在資料裡還不存在 |

## 附錄 B：觸發條件能寫什麼

「什麼時候會遇到這個事件」，目前能判斷的有六種：

| 你可以寫 | 大綱裡的例子 |
|---|---|
| 某件事發生過了 | 打倒半魚人祭司后 |
| 某件事**還沒**發生 | 首次…（等於「這件事還沒發生過」） |
| 某位神的侵蝕度 ≥ N% | 【深淵】的侵蝕度為 50% 以上 |
| 某位神的侵蝕度 < N% | |
| 身上某一類東西 ≥ N 件 | 持有 20 張以上的武器牌／身上有糧食 |
| 身上某一類東西 < N 件 | 持有的神牌少於 3 張 |
| 這場遊戲已經玩了 ≥ N 秒 | 遊戲進行一段時間後（約 800 秒？） |

**條件可以疊**，全部成立才會遇到。例如「侵蝕度 50% 以上**而且**身上有糧食」。

**目前只有「而且」，沒有「或者」。** 需要「A 或 B」的話跟我們說，我們再加。

## 幾條硬限制

| 限制 | 為什麼 |
|---|---|
| **選項最多 3 個** | 對話框只有三個位置 |
| **每組台詞至少 3 句** | 少於 3 句玩家連點就會聽到重複 |
| **名字不要重複** | 兩件東西同名的話，遊戲裡分不出來 |
| **改名字隨時可以，而且免費** | 名字跟遊戲內部的編號是分開的，你想改幾次都行 |

## 有問題找誰

- **這個能不能做到** → 問我們，不要自己猜著閃避。做不到我們會告訴你替代方案
- **收藏品／神牌的效果細節** → 戰鬥組（Romtyui）
- **這一段該怎麼斷句** → 你決定，那是你的專業
