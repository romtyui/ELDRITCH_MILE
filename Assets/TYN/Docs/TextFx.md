# 文字特效標註（給文案）

2026-11-23 起，遊戲裡**任何會顯示出來的文字**都可以用類似 HTML 的標籤，讓個別詞句動起來。事件內文、對話、選項、道具說明都適用，不用請程式另外設定。

## 寫法

| 效果 | 標籤 | 中文寫法 | 例子 |
|---|---|---|---|
| 抖動（恐怖遊戲那種顫抖） | `<shake>…</shake>` | `<抖>…</抖>` 或 `<抖動>…</抖動>` | `他的聲音<shake>不像人類</shake>。` |
| 上下起伏 | `<wave>…</wave>` | `<波>…</波>` 或 `<波浪>…</波浪>` | `<wave>海浪在呼喚你</wave>` |
| 忽明忽滅 | `<flicker>…</flicker>` | `<閃>…</閃>` 或 `<閃爍>…</閃爍>` | `<閃>那盞燈</閃>熄了又亮。` |

**強度**：在標籤後面加 `=數字`，預設是 1。

```
<shake=0.5>微微發抖</shake>
<shake=2.5>快逃</shake>
<抖=3>不要回頭</抖>
```

## 可以混用的

TextMeshPro 原本的標籤照樣能用，也可以跟特效疊在一起：

```
<color=#C33><shake=2>血</shake></color>
<b><wave>深淵</wave></b>
<size=120%><shake>到底是誰</shake></size>
```

## 不能做的

- **特效不能互相包。** `<shake><wave>…</wave></shake>` 只會留外面那一層。要兩段不同效果，就分開寫在相鄰的字上。
- 標籤要成對，`<shake>` 一定要有 `</shake>`。少了結尾，後面整段都會一起抖。
- 在 Unity 編輯器**沒按 Play 的時候**，標籤會以原文顯示；按下 Play 才會變成效果。

## 打字機效果

對話框是一個字一個字打出來的：還沒打到的字不會動，打到了才開始抖。

## 程式這邊（給維護的人）

`Assets/TYN/UI/TextFx/TextFx.cs`。文字一出現特效標籤，這個元件就會自動掛到那個 TMP 上，並把標籤轉成 TMP 的 `<link="fx:…">`。之後每一幀只移動那幾個字的頂點，不會重新排版。抖動幅度、速度等參數在元件的 Inspector 上調；這些參數是每個文字物件各自一份。
